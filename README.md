# DONAT CORE

Публичная платформа донатов для стримеров в стиле **Neon Core**: чёрный фон, фиолетовые и бирюзовые неоновые акценты.

## Текущий этап
Первый этап — адаптивная панель стримера для Android и компьютера: баланс в ₽, история донатов, публичный профиль и настройки.

## Важно
Это прототип интерфейса. Все суммы в демонстрационной версии условные; реальные платежи, регистрация, база данных и вывод средств не подключены. Баланс в демо не является реальными денежными средствами.

## План развития
1. Добавить адаптивный интерфейс личного кабинета.
2. Опубликовать фронтенд.
3. Создать backend, безопасную авторизацию и базу данных.
4. Проверить требования и доступность платёжных провайдеров для нужной юрисдикции и валюты.
5. Подключать реальные платежи только с серверной проверкой уведомлений провайдера и безопасной обработкой выплат.
